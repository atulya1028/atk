FAULT TOLERANCE END-TO-END TRY-CATCH ARCHITECTURE

Zero-Crash Multi-Tier Exception Architecture

Ensuring zero uncaught errors and graceful degradation across all layers.

UI & Action Layer

Every asynchronous mutation (deleting submissions, adding doctors, resetting surveys, saving thresholds) is enclosed in dedicated try ... catch blocks with contextual error snackbars.

Transport & Storage Layer

_sendSafe and _safeJsonDecode trap timeouts, DNS drops, and malformed HTML responses. CSV exporter falls back to data-URI if web blobs fail.

Backend & Process Layer

Express async route wrapper bubbles errors to global middleware. Process-level unhandledRejection and uncaughtException prevent PM2 daemon termination.
