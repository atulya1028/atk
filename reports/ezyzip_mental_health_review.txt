EZYZIP REFERENCE REPORT
Mental Health path, survey flow, and question inventory
Prepared: 17 November 2026

SCOPE AND METHOD
This report documents the Mental Health-related parts of the ezyZIP project copy
available at Downloads/ezyZip. It reviews the Flutter screens and API flow, then
checks the included SQLite development database. It is a focused report about
the Mental Health path, not a complete inventory of every file in the project.

KEY FINDING
ezyZIP has a selectable Mental Health path in its interface and supports sending
the MENTAL category to its survey API. However, the included development database
contains no MENTAL-category sections or questions. The questions listed later in
this report are mental-health-related questions stored under the ADDICTION path;
they are not a separate MENTAL questionnaire.

1. THE MENTAL HEALTH SCREEN
The old app's screen is named "Choose Your Path". Its subtitle reads:
"Select the assessment track you want to focus on today."

It displays two large cards on a full-screen gradient background:
  * Addiction Assessment - "Substance use and dependency screening"
  * Mental Health - "Emotional and psychological well-being"

The Mental Health card uses a psychology icon, translucent white card fill, and
white text. While a path is being saved, the screen shows a centered loading
indicator and disables both cards. On success, the app replaces this screen with
Home. This is a path-selection screen; the old Flutter source has no separate
Mental Health questionnaire page file.

2. WHAT HAPPENS WHEN MENTAL HEALTH IS SELECTED
1. The card calls UserService.selectPath("MENTAL").
2. The app POSTs surveyCategory=MENTAL to /user/select-path.
3. On success, it stores MENTAL in local preferences as selectedCategory.
4. The app navigates to Home. The Home header displays "Mental Health" as the
   active category; tapping that category chip opens path selection again.
5. SurveyApiService reads the selected category and sends it with the survey
   type when starting a submission and requesting questions.
6. The question API filters database records by both surveyType and
   surveyCategory. Returned questions become individual question steps. Answers
   are sent as the patient advances, and completed answers can be resumed.

The question endpoint is category-aware, so a real database containing MENTAL
question records could serve a Mental Health assessment. The interface and API
support alone do not provide those question records.

3. DATABASE CONTENT FOUND IN THE PROVIDED PROJECT COPY
The included backend/prisma/dev.db contains:
  * ADDICTION / INITIAL: 26 questions in 5 sections
  * ADDICTION / DETAILED: 71 questions in 7 sections
  * MENTAL / INITIAL: 0 sections and 0 questions
  * MENTAL / DETAILED: 0 sections and 0 questions

Therefore, this database snapshot cannot populate a separate Mental Health
questionnaire. With no question records, the question endpoint's MENTAL query
returns an empty list. The old survey-flow code always adds a Welcome/Start
step before adding database questions, so the included data does not supply any
actual MENTAL question steps.

This conclusion applies to the project copy and development database inspected.
It does not prove that a separately hosted ezyZIP database has no MENTAL data.

     Options: Normal / Abnormal

q48  How would you describe your current thought processes?
     Options: Normal / Abnormal

q49  Have you experienced any unusual perceptions, such as seeing or hearing

The option records inspected for these seven questions all have scoreValue 0.
The included data therefore does not define a numeric score for this section.

7. WHAT THIS MEANS FOR A CLONE
To reproduce the old screen's visible Mental Health entry point, copy its
selection behavior and category indicator. To reproduce a working, separate
Mental Health assessment, a MENTAL question bank is also required. It is absent
from the local ezyZIP database inspected here. The seven Mental Status
Examination questions are the closest distinct question set present, but the
old database places them in Detailed Addiction and assigns them no numeric
score.
